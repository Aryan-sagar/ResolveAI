# Password Reset FAQ

## Resetting a Password
Customers who forgot their password can reset it from the account login page by selecting the "Forgot password" option.

A password reset link will be sent to the email address associated with the account.

## Reset Link
For security reasons, password reset links expire after a limited period.

If the link has expired, request a new password reset email.

## Login Problems
If the customer cannot access the registered email address or continues to have trouble logging in, they should contact support for assistance.
